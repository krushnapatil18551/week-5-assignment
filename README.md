# TaskFlow — Week 5 JavaScript Project

## Project overview
TaskFlow is a responsive task-management web application built with HTML, CSS and vanilla JavaScript. Users can organize personal, study, work and other tasks.

## Features
- Add tasks with category selection and input validation
- Edit task titles and delete tasks
- Mark tasks complete or active
- Search by task title
- Filter by status and category
- Clear all completed tasks
- Live task counters and completion progress bar
- Save tasks in browser `localStorage`
- Responsive layout for desktop and mobile

## Technologies
- HTML5
- CSS3 (responsive media queries, Flexbox and Grid)
- JavaScript (ES6+)
- Browser DOM APIs and `localStorage`

## JavaScript concepts demonstrated
Variables, functions, arrays, objects, conditional statements, loops, array methods (`filter`, `map`, `some`, `find`, `forEach`), DOM selection and creation, form submission, click/change/input events, JSON, and local storage.

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Add a task and try the search, category/status filters, edit, delete, and completion controls.

No installation or server is required.
